# /mc

Mission Control orchestrator hub. Reads v5 state from `control/v5/`, resolves routes, runs the pipeline.

Invoke skill: `mc`

Subcommands: init / start / feature / braindump / portfolio / validate / handoff / resume.

Optional argument: `[subcommand]` — e.g. `/mc resume {slug}` or `/mc feature {slug}`.
