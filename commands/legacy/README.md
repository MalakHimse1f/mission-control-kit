# Legacy v3 commands

These commands remain for **resume-only** on projects mid-migration from Mission Control v3.

| Command | v4 replacement |
|---------|----------------|
| `/mc-refine` | `/mc-feature` → clarify → `mc-prd` |
| `/mc-layout` | `/mc-feature` → interaction → `mc-mock` |
| `/mc-plan` | `/mc-feature` → `mc-platform-plan` |
| `/mc-braindump` | `/mc-feature` (alias) |

New work should always use `/mc-start`, `/mc-feature`, or `/mc`.
