# Build Gates

Quality and completeness checks for v5 feature builds.

## Purpose

This document defines the gates that must pass before a feature is considered complete. Build subagents must satisfy all gates before marking work as done. Spec reviewers verify gate compliance.

## Content Sections

- Unit test coverage requirements
- Integration test expectations
- Code review checklist (MVVM boundaries, patterns, style)
- Documentation completeness (API docs, usage examples)
- Performance benchmarks (if applicable)
- Accessibility compliance (WCAG 2.1 AA minimum)
