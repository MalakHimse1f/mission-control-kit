# UX Patterns

Standard interaction patterns and user journeys for v5 features.

## Purpose

This document codifies proven user interaction patterns that maintain consistency across features. It guides orchestrators and UX brainstorming subagents in designing coherent user experiences aligned with the v5 philosophy: decisions are reviewable via illustrated, interactive diagrams.

## Content Sections

- Navigation patterns (tab navigation, sidebar, breadcrumbs, etc.)
- Decision point patterns (interactive diagrams, selection UI)
- Progress indicators and state feedback
- Common flows (feature creation, review, iteration)
- Interaction model for diagram-based decisions
