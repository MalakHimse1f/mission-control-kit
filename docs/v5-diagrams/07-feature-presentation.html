Team Collaboration — Spec

Status: UX decisions in progress · 4 of 7 decisions captured

Overview

Real-time collaboration on project documents. Multiple users can open the same document and see each other's cursors, edits, and presence in real time. Conflicts are resolved automatically via CRDT.

User stories

  • As a team member, I can see who else is currently viewing a document.
  • As an editor, my changes appear on other peers' screens within ~200ms.
  • As a reviewer, I can see colored cursors with the author's name attached.

Non-functional requirements

  • Offline-tolerant: edits made while offline merge cleanly when reconnected.
  • No central transform server — CRDT removes that coordination requirement.
  • Supports up to 16 concurrent peers per document.

Out of scope

Comment threads, suggested edits, and version history are deferred to a follow-up feature.

Phase 1 — Data model & transport

Wire up the underlying CRDT (Yjs) and pick a transport. Decided on WebSockets via y-websocket with a tiny relay server. No conflict-resolution code lives in our app — Yjs handles it.

  • Pick CRDT library

Phase 2 — Presence & cursors

Layer the presence channel on top of the CRDT awareness API. Render avatar stack and remote cursors with author colors.

Phase 3 — Persistence & resilience

Periodically snapshot the Y.Doc to Postgres. Reconnect with exponential backoff.

003 — Switched from Operational Transform to CRDT

OT requires a central server to transform concurrent ops; this adds an availability point we don't want. CRDTs let peers merge state independently and the math guarantees convergence. Picked Yjs over Automerge — smaller bundle, mature provider ecosystem.

002 — Cursor color allocation strategy

Hash user id → HSL hue. Fixed saturation and lightness so contrast stays predictable. Falls back to a small palette of 8 distinct colors when the user is a guest.

001 — Initial braindump

Captured original requirements. Up to 16 concurrent peers, offline-tolerant, no central transform server. Comments and version history explicitly out of scope.
