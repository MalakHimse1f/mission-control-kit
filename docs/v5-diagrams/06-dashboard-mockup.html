Typical workflows

  1. Brand new project: /mc-start → /mc-init → /mc-v5 (per feature)
  2. Add a feature: /mc-v5 → brainstorm → decisions saved → /mc-v5-resume <slug> → /mc-build
  3. Quick feature (no brainstorm): /mc-feature → /mc-layout → /mc-plan → /mc-build → /mc-validate
  4. End of session: /mc-handoff → /clear → (new session) /mc-v5-resume <slug>
