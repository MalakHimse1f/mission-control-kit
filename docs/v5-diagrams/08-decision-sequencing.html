Gate Logic — Which Task Types Are Deferred In Each Phase
During UX
deferred → ui-implementation architecture build
During UI
deferred → architecture build
During Architecture
deferred → build
Any phase
advisory (never deferred) → research brainstorm
shouldDefer(taskType, stage) in lib/v5/mc-router.mjs compares each task's required phase against the canonical phase order.
Non-canonical stages pass through the gate. Dashboard buckets (needs-input ready in-progress complete) are not canonical phases — they don't trigger the gate. The orchestrator MUST resolve a canonical phase via currentPhase({ slug, controlRoot }) from lib/v5/decision-gate.mjs before calling resolveRoute.
