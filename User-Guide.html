Install (first time)

Put this kit folder inside your project, then install. Requires Node.js.

Typical layout:

your-project/
  mission-control-kit/   ← this folder
  …your app…

Mac — double-click

Opens a folder picker, then installs safely.

Run installer

Windows

Double-click Run-Installer.hta (Install or Update) or run PowerShell:

& ".\mission-control-kit\install.ps1" -ProjectRoot .

Update only

Terminal (Mac / Linux)

chmod +x mission-control-kit/install.sh && mission-control-kit/install.sh .

Update (safe upgrade)

Updates refresh orchestrator docs and skills. Your features/ specs, journals, and custom/ overrides are never overwritten.

Mac — double-click

Run updater

Chat

In Cursor or Claude Code:

/mc-upgrade

Terminal

node mission-control-kit/scripts/mc-upgrade.mjs .

Check only: --check · Preview: --dry-run · Fetch release: --fetch

Dashboard

The v5 dashboard is a live server — launch it from the terminal at your project root:

node mission-control-kit/control/scripts/v5/dashboard-server.mjs .

Commands

CommandWhen
/mcMission Control hub — routes any input to the right workflow
/mc-startNew product — establishes tech stack and seeds first feature
/mc-initExisting codebase — set tech stack once
/mc-featureNew feature in established product
/mc-braindumpRun the brainstorm flow for the active feature
/mc-layoutWireframe + layout step — produces HTML mocks
/mc-planGenerate phased implementation plan from approved spec
/mc-buildDispatch the build subagent
/mc-validateValidation gate between pipeline phases
/mc-handoffEnd-of-session handoff — run before /clear
/mc-resume <slug>Resume a feature where you left off
/mc-portfolioMulti-feature build order review
/mc-upgradeSafe kit update
