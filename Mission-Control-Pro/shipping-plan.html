Org admin · Phases 6–9

Teams, standards, projects, items.

The org-level inputs that shape every agent run. Teams route workflows to roles. Standards shape how agents work. Projects model the org's portfolio. Items capture the actual work — Features, Bugs, Epics.

Cloud visibility · Phases 13–14

Watch it. Answer it.

Phases 13 and 14 are the dashboard. Phase 14 closes the loop: agent → cloud → user → agent. This is the demo. This is what a CTO is paying for.

  • /dashboard/item/{id} drill-down
  • Filter by Project / Item / Epic / branch

Before Phase 1 starts

Five questions to lock.

These don't block planning, but they block the first line of code. Get them off the list before sprint zero.

Question 01
Marketing copy ownership
Who writes the hero + subtext? Lean: founder writes v0, marketing iterates.
Question 02
Domain confirmation
Is missioncontrol.pro registered? If not — fallback domain?
Question 03
Org slug uniqueness
Globally unique or per-tenant? Lean: globally unique (used in URLs).
Question 04
Email verification policy
Required at signup? Lean: required, with a 7-day grace period.
Question 05
First curated workflow (Phase 12)
Which workflow ships first? Lean: mcp-feature — braindump → spec → plan → build → validate. Now Item-aware.
