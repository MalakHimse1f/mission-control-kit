Transcript privacy — what leaves the user's machine?

Original concern If we mirrored the agent transcript to the cloud, sensitive code snippets from a customer's private repo would end up in Supabase. We needed a clear answer on what the bridge is permitted to send, where that rule lives, and how a customer can verify it.
Resolved 2026-05-26 · Same as #02

This question is fully answered by Issue 02 — journal-driven visibility. The bridge only sends events the orchestrator skill and subagents explicitly journal, plus decide requests. Free-form chat never leaves. File contents never leave unless explicitly attached to a journal entry by the skill author.

✓ Privacy contract
The bridge's outbound channel — fully enumerable
What can leave the machine
Journal entries — text the skill explicitly emits
Stage / state diffs — minimal, structured
Decision requests — workflow-defined shape
Bridge heartbeat — device id, timestamp, no content
Audit events — spawn results, sync events
Free-form chat — never
Tool call payloads — never
File contents — never (unless attached to a journal entry by the skill)
Why this works as a contract
  • The bridge channel is enumerable — auditable in code, not by trust
  • The skill author controls what gets attached, per step
  • "What does the cloud see?" has a definitive list
  • Enterprise security review has a clean answer
Sharp edges
  • A poorly-written skill could journal a code snippet by mistake — we need orchestrator-skill review guidance
  • Workflow authors who use decide for long code reviews are sending code intentionally — make that obvious in the UI
  • Enterprise tier: option to disable all cloud journal bodies (metadata-only) as a future opt-in
Where this lives in the code Bridge has a hard-coded event-type allowlist for outbound messages. Anything that isn't one of the enumerated types is dropped at the boundary, not at the transport layer. The orchestrator skill ships with a documented set of journal helpers — using anything other than those helpers is a lint warning. Enterprise self-host can additionally redact journal bodies before they leave the bridge.
