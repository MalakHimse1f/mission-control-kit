Cursor support roughly doubles bridge integration cost.
Where on the timeline does Cursor fit?

The problem Claude Code and Cursor have different hook surfaces, different plugin models, and different CLI postures. Supporting both means two integration shims, two sets of orchestrator skills, two test matrices, and two parallel failure modes for support. Cursor's extension surface is also less mature, so we'd be tracking a moving target.
Decided 2026-05-26 · Path A

Claude Code only for v1. Bridge core speaks to an AgentAdapter interface — Claude is the first implementation; Cursor lands as a drop-in adapter in v2 when a design-partner team formally blocks on it. Lock the interface before shipping Claude.
