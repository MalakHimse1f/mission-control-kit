02 / 09
The Problem

Every dev runs AI agents.
Nobody at the org level knows what they're doing.

Engineering leadership has spent the last two years buying Copilot, Cursor, and Claude Code seats. The result: every developer has a powerful agent — and zero shared discipline.

01
Invisible work
Engineering managers can't see what agents are working on. No portfolio view, no progress, no blockers.
02
Inconsistent output
Each dev has different prompts, different patterns. Code style drift, missed test coverage, bypassed standards.
03
PRDs in chat history
Specs and decisions live in ephemeral conversations. PMs and designers can't follow, review, or hand off.
04
No org guardrails
Org architecture rules, design tokens, A11y baselines — nothing reaches the agent at dispatch time.
03 / 09
The Insight

Don't build another agent.
Route the agents you already have.

Our position
We don't own the agents. We don't make the agents. We route agent and user interactions so the org can see them and shape them.
Claude Code and Cursor are excellent. The team already pays for them. The gap is org-level orchestration — and that's the wedge.

This is the same pattern that worked for GitHub Actions, Linear, and Sentry: don't replace the tool, surround it. Be the cloud-side coordination layer for work that runs locally.

08 / 09
What we have to get right

The risks we've identified — and how we're handling them.

Risk Mitigation
Agent vendor APIs change Use stable extension points (hooks, slash commands). Pin minimum versions. Run a compat lab.
Bridge install friction Single-binary installer, auto-update, system tray icon. Skip MSI/MDM complexity in v1 by targeting individual installs.
Security — bridge can run commands Signed event envelopes, allowlist of spawnable commands, user-confirm on first run, kill-switch in web app.
Workflows are confidential Supabase RLS, encryption at rest, audit log. Enterprise tier offers self-hosted bridge fleet.
Cursor support cost Ship Claude Code-only for v1. Add Cursor only after design partners ask for it explicitly.
