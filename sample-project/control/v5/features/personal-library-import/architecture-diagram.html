Source Connector Pattern

How we structure per-source importers — drives extensibility, isolation, and infra cost.

Architecture — Pending Decision
Each source is a module behind a shared SourceConnector interface
Plugin modules
Each source is its own module behind a common SourceConnector interface. Add a source by dropping in a file.
A single ImportService with a switch-case per source
Monolithic service
One ImportService handles every source via a switch-case. Simplest code, hardest to extend.

Each source is its own Cloud Function. Strong isolation and per-source scaling; cold-start latency + infra cost.
