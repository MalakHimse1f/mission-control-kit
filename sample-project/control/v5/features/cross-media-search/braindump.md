# Cross-Media Search — Braindump

- I want one search box. Type "Dune," get everything: my library copies, the book on Open Library, the movies on TMDB, the game on IGDB.
- Currently I have to context-switch between sources. Stupid.
- The product owns my collection. It should also own discovery within those same content domains.
- External catalogs available: TMDB (movies + TV), IGDB (games), Open Library (books), Comic Vine (comics). All have decent free tiers.
- Don't make the user choose which catalog. Fan out. They came here with a title, not a media type.
- Result grouping IS important though. "Dune" the book is a different thing than "Dune" the movie is a different thing than "Dune: Spice Wars" the game. Don't merge them in a flat list.
- Tabbed sections. Books / Movies / TV / Games / Comics. Plus a "in your library" highlight at the top of each tab when relevant.
- Search bar lives in the top nav. Persistent. Cmd-K. Standard.
- Mobile: collapse to icon, expand on tap. Results in a single scroll.
- Quick-add is the killer feature. I see "Dune" on TMDB, I click +, it's in my backlog. No modal, no confirm.
- The hover-only "+" is a desktop pattern that breaks mobile. Just leave the button there.
- Fan-out is per-request. Server-side. Parallel.
- 800ms timeout per source. Some are slow. Don't let one slow source block the whole render.
- SSE streams partial results back. Library + Open Library usually first (Open Library is fast, library is local). TMDB second. IGDB slowest.
- Caching: yes. Redis. 24h TTL. Same query in the same day = no upstream call.
- Normalize the cache key: lowercase, collapse spaces, strip punctuation. So "Dune!", "DUNE", and "dune" all hit the same row.
- Comic Vine has been the flakiest of the four. Need a real failure mode for when it times out — error chip on that tab, not on the whole page.
- All four down at once: library-only results + banner. Don't block search entirely.
- Short queries (1 char) — don't fan out. Just prefix-match the library. Anything less is a waste of bandwidth.
- Duplicates: my Open Library result for "Dune" already exists in my library? Collapse, library version wins. Show the library indicator.
- Cover art is sometimes slow. Render the title + meta immediately, lazy-load the cover. Don't wait.
- One thing I want: keyboard navigation through results. Cmd-K to open, arrows to navigate, enter to open, shift-enter to quick-add. Power-user friendly.
- The "expansion outranks base game" issue on IGDB: known. Not fixing pre-launch. Add a heuristic later.
- Logging: search query, sources hit, sources timed out, result clicked, quick-add fired. We'll want this data.
- Privacy: searches are personal data. Don't log queries to third parties.
- Future: voice / fuzzy phonetic search. Saved searches. Search-in-content. All separate.
- Shipped this on 2026-05-22. Numbers looked good after a week.
